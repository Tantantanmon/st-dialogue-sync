# Dialogue Sync

번역 프롬프트를 쓸 때, 번역문 파트의 대사에서 원문이 빠지는 경우를 고쳐 줍니다.

원문 파트에 이렇게 나왔는데

```
"Looks fine. Just bag 'em up, please. (괜찮아 보이네요. 그냥 담아주십쇼.)"
```

번역 파트에는 이렇게만 나올 때

```
"괜찮아 보이네요. 그냥 담아주십쇼."
```

메시지의 ✂ 버튼을 누르면 원문을 찾아서 붙여 줍니다.

```
"Looks fine. Just bag 'em up, please. (괜찮아 보이네요. 그냥 담아주십쇼.)"
```

## 설치

SillyTavern의 확장 탭에서 **Install extension** 을 누르고 이 저장소 주소를 붙여 넣으세요.

```
https://github.com/Tantantanmon/st-dialogue-sync
```

또는 저장소를 직접 아래 경로에 두어도 됩니다.

```
SillyTavern/public/scripts/extensions/third-party/st-dialogue-sync/
```

## 설정

확장 탭 → Dialogue Sync 를 엽니다.

1. 쓰고 있는 번역 프롬프트를 붙여 넣습니다.
2. **태그 찾기** 를 누릅니다. 원문 태그와 번역 태그가 자동으로 채워집니다.
3. 채워진 값이 맞는지 확인합니다. 틀렸으면 직접 고치세요.

**태그 찾기** 가 실패하면 **AI로 분석** 을 누르세요. 현재 연결된 모델이 프롬프트를 읽고 태그를 찾아 줍니다. 설정할 때 한 번만 호출합니다.

### 문장 매칭 기준

원문 파트의 번역과 번역 파트의 문장은 표현이 조금 다를 수 있습니다. 이 값은 얼마나 비슷해야 같은 대사로 볼지 정합니다.

- 대사가 안 붙으면 값을 낮추세요
- 엉뚱한 원문이 붙으면 값을 올리세요

## 동작 방식

- ✂ 버튼을 누를 때만 실행됩니다. 자동으로 바꾸지 않습니다.
- AI 응답에만 버튼이 붙습니다. 직접 쓴 메시지에는 붙지 않습니다.
- 이미 원문이 붙어 있는 대사는 건너뜁니다. 여러 번 눌러도 중복되지 않습니다.
- 짝을 찾지 못한 대사는 그대로 둡니다.
- 나레이션과 원문 파트는 건드리지 않습니다.
- 바꾼 뒤에는 되돌리기 버튼이 나타납니다.

## 지원하는 형식

원문과 번역이 서로 다른 문자를 쓰면 동작합니다. 한국어, 일본어, 중국어, 러시아어, 아랍어, 태국어를 자동으로 인식합니다.

따옴표는 `" "`, `“ ”`, `「 」`, `『 』` 를 인식합니다.

## 잘 안 될 때

**버튼을 눌러도 아무 변화가 없습니다**

- 확장 탭에서 태그가 제대로 채워져 있는지 확인하세요
- 이미 모든 대사에 원문이 붙어 있는 상태일 수 있습니다
- 문장 매칭 기준을 낮춰 보세요

**엉뚱한 원문이 붙습니다**

되돌리기 버튼을 누른 뒤 문장 매칭 기준을 올리고 다시 시도하세요.

**태그를 찾지 못합니다**

프롬프트가 XML 태그로 파트를 나누지 않는 구조일 수 있습니다. 이 확장은 `<태그></태그>` 로 감싼 형식을 전제로 합니다.

## 빠른 답장 / 명령어 (v1.1.0)

가위 버튼 대신 명령어로도 실행할 수 있습니다.

- `/dsync` — 가장 최근 AI 메시지를 교정합니다
- `/dsync 12` — 12번 메시지를 교정합니다

가위 버튼은 대사를 `"영어 (한국어)"` 형식으로 맞춥니다. 아래 형태를 모두 고칩니다.

- `"영어" (한국어)`
- `"영어" ("한국어")`
- `"영어 ("한국어")"`
- `"영어" "한국어"`
